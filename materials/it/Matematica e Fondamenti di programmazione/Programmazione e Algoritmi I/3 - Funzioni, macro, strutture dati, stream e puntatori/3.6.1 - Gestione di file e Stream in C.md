# 3.6.1 - Gestione di file e Stream in C

## Introduzione intuitiva

Tutte le variabili, gli array e le strutture che abbiamo creato finora vivono nella **memoria centrale (RAM)**: non appena il programma termina (o si spegne il computer), tutti i dati in RAM svaniscono nel nulla!

Per conservare i dati in modo permanente (**persistenza**) o elaborare grandi quantità di informazioni salvate su disco (SSD/Hard Disk), un programma deve saper leggere e scrivere **File**.

Il linguaggio C affronta questo problema con una straordinaria eleganza progettuale: estende ai file su disco la stessa identica astrazione di **Stream (Flusso di byte)** che abbiamo già usato nella Lezione 2.3.1 per la tastiera (`stdin`) e lo schermo (`stdout`). Una volta aperto un file e ottenuto un puntatore di controllo **`FILE *`**, leggerlo o scriverlo con `fscanf` e `fprintf` è quasi identico a usare `scanf` e `printf`!

---

## L'Astrazione di Stream, `FILE *` e File di Testo vs File Binari

### Il puntatore opaco `FILE *`
In `<stdio.h>` è definito un tipo struttura speciale chiamato **`FILE`**. Il programmatore non deve mai accedere direttamente ai campi interni di `FILE` (per questo si chiama **tipo opaco** o *handle*), ma interagisce sempre tramite un **puntatore `FILE *fp`**, che contiene tutte le informazioni necessarie al sistema operativo per gestire il flusso:
- Il descrittore del file aperto nel sistema operativo.
- Il **buffer di memoria** per velocizzare le letture/scritture su disco.
- Il **cursore di posizione corrente** (*file position indicator*, l'indice del prossimo byte da leggere o scrivere).
- I flag di stato (**Fine del file `EOF`** ed **Errore di I/O**).

### File di Testo vs File Binari
1. **File di Testo (`.txt`, `.csv`, `.c`, `.json`)**:
   - I dati sono convertiti e salvati come **sequenze di caratteri ASCII/UTF-8 leggibili da un essere umano** (e apribili con qualsiasi editor di testo), organizzate in righe terminate da `\n`.
   - *Esempio*: il numero intero `123456` viene scritto come i **6 caratteri ASCII** `'1'`, `'2'`, `'3'`, `'4'`, `'5'`, `'6'` (6 byte).
2. **File Binari (`.bin`, `.dat`, immagini, eseguibili)**:
   - I byte contenuti nella memoria RAM delle variabili o delle `struct` vengono **copiati direttamente su disco così come sono**, senza alcuna conversione testuale!
   - *Esempio*: qualsiasi `int` (anche `123456` o `2000000000`) occupa sempre esattamente **4 byte** su disco, risultando più compatto e molto più veloce da leggere/scrivere in blocco, ma non leggibile con un normale blocco note.

## Il Ciclo di Vita di un File: `fopen`, Controllo `NULL` e `fclose`

Ogni operazione su file segue rigorosamente **3 fasi obbligatorie**:

```mermaid
flowchart LR
    OPEN["1. Apertura\nFILE *fp = fopen(nome, modo);"] --> CHK{"fp == NULL ?"}
    CHK -->|"Sì (Errore!)"| ERR["Gestione errore\nperror(\"Errore\");\nreturn 1;"]
    CHK -->|"No (Valido)"| RW["2. Lettura / Scrittura\nfscanf, fprintf, fgets,\nfread, fwrite, fseek"]
    RW --> CLOSE["3. Chiusura obbligatoria\nfclose(fp);"]
```

### 1. Apertura con `fopen(percorso, modalita)` e controllo `if (fp == NULL)`
```c
FILE *fp = fopen("dati.txt", "r");
if (fp == NULL) {
    perror("Impossibile aprire dati.txt"); /* Stampa su stderr il motivo esatto dell'errore! */
    return 1;
}
```
> **Regola ferrea**: **`fopen` restituisce `NULL` se l'apertura fallisce** (ad esempio perché il file da leggere non esiste, il percorso è sbagliato o non abbiamo i permessi di scrittura sul disco). Passare un puntatore `fp == NULL` a `fscanf` o `fprintf` provoca un immediato **Segmentation Fault**! Controlla **sempre** `if (fp == NULL)` subito dopo `fopen`.

### Tabella completa delle Modalità di apertura (`mode`)

| Modalità Testo | Modalità Binaria | Operazioni consentite | Se il file ESISTE già | Se il file NON ESISTE |
| :---: | :---: | :--- | :--- | :--- |
| **`"r"`** | **`"rb"`** | **Sola Lettura** (*Read*) | Legge dall'inizio del file | **Fallisce e restituisce `NULL`!** |
| **`"w"`** | **`"wb"`** | **Sola Scrittura** (*Write*) | **CANCELLA TUTTO il vecchio contenuto (tronca a 0 byte)!** | Lo crea nuovo |
| **`"a"`** | **`"ab"`** | **Aggiunta in Coda** (*Append*) | Scrive sempre in fondo senza cancellare il vecchio contenuto | Lo crea nuovo |
| **`"r+"`** | **`"r+b"`** | Lettura e Scrittura | Legge/scrive dall'inizio senza cancellare | **Fallisce e restituisce `NULL`!** |
| **`"w+"`** | **`"w+b"`** | Lettura e Scrittura | **Cancella tutto il vecchio contenuto!** | Lo crea nuovo |
| **`"a+"`** | **`"a+b"`** | Lettura e Aggiunta in coda | Legge ovunque, ma scrive sempre in fondo | Lo crea nuovo |

### 2. Chiusura con `fclose(fp)`
Quando abbiamo finito di usare il file, dobbiamo **sempre** chiuderlo con:
```c
fclose(fp);
```
*Perché `fclose` è così importante?* Perché le scritture su disco sono **bufferizzate** in RAM per motivi di efficienza: se il programma termina bruscamente o dimentica `fclose(fp)`, gli ultimi dati scritti potrebbero rimanere nel buffer in RAM e non finire mai sul disco (oppure potremmo esaurire il numero massimo di file apribili contemporaneamente dal processo).

## Operazioni su File di Testo e la Trappola di `feof(fp)`!

Tutte le funzioni di `<stdio.h>` viste per tastiera e schermo hanno la loro gemella per i file:

| Su Standard Stream (`stdin` / `stdout`) | Su File di Testo (`FILE *fp`) | Comportamento e Valore di ritorno per fine file / errore |
| :--- | :--- | :--- |
| `printf("fmt", ...)` | **`fprintf(fp, "fmt", ...)`** | Scrive testo formattato sul file `fp`. *(Nota: `fprintf(stdout, ...)` equivale a `printf(...)`!).* |
| `scanf("fmt", ...)` | **`fscanf(fp, "fmt", ...)`** | Legge dati formattati da `fp`. Restituisce il **numero di variabili lette con successo**, oppure **`EOF`** a fine file. |
| `fgets(buf, dim, stdin)` | **`fgets(buf, dim, fp)`** | Legge una riga intera (fino a `\n` o `dim-1` byte). Restituisce `buf`, oppure **`NULL`** a fine file! |
| `getchar()` | **`fgetc(fp)`** | Legge un singolo carattere (ritorno **`int`!**). Restituisce **`EOF`** a fine file. |
| `putchar(c)` | **`fputc(c, fp)`** | Scrive il carattere `c` sul file `fp`. |

### Perché NON bisogna MAI usare `while (!feof(fp))` prima della lettura!
Questo è l'errore più diffuso in assoluto nella programmazione C sui file:
```c
/* CODICE SBAGLIATO: stampa o elabora L'ULTIMA RIGA DUE VOLTE! */
while (!feof(fp)) {
    fscanf(fp, "%d", &x); /* Quando finisce il file, questa fscanf FALLISCE... */
    printf("%d\n", x);    /* ...ma il ciclo esegue comunque printf stampando il VECCHIO x! */
}
```
**Spiegazione tecnica**: La funzione `feof(fp)` restituisce Vero (`!= 0`) **SOLO DOPO che un'operazione di lettura ha tentato di leggere oltre la fine del file ed è fallita** (non "indovina" in anticipo che il file sta per finire!).
Se quindi usate `while (!feof(fp))`, dopo aver letto l'ultimo numero del file `feof(fp)` è ancora **Falso**; il programma entra nel ciclo un'ultima volta, `fscanf` fallisce perché il file è finito (lasciando in `x` il valore del giro precedente!) e voi elaborate o stampate **l'ultimo dato due volte**!

> **Modo CORRETTO e universale per leggere un file fino alla fine**:
> Mettere **direttamente la funzione di lettura nella condizione del `while`** controllandone il valore di ritorno:
> - Con `fscanf`: **`while (fscanf(fp, "%d", &x) == 1) { ... }`**
> - Con `fgets`: **`while (fgets(buf, sizeof(buf), fp) != NULL) { ... }`**
> - Con `fgetc`: **`while ((c = fgetc(fp)) != EOF) { ... }`**

## Operazioni su File Binari (`fread`, `fwrite`) e Navigazione (`fseek`, `ftell`)

### 1. Lettura e scrittura in blocco su file binari: `fread` e `fwrite`
Per leggere o scrivere un array o una `struct` direttamente in binario (file aperto con `"rb"` o `"wb"`):
```c
size_t fread(void *ptr, size_t dim_elemento, size_t num_elementi, FILE *fp);
size_t fwrite(const void *ptr, size_t dim_elemento, size_t num_elementi, FILE *fp);
```
Entrambe restituiscono il **numero di elementi effettivamente letti o scritti** (che deve essere uguale a `num_elementi` se tutto è andato bene):
```c
Studente s = {101, "Anna", 29.5};
/* Scriviamo 1 elemento di dimensione sizeof(Studente) sul file binario fp: */
fwrite(&s, sizeof(Studente), 1, fp);

/* Oppure scriviamo un intero vettore di 50 int in un colpo solo: */
int v[50];
fwrite(v, sizeof(int), 50, fp);
```

### 2. Accesso diretto (Random Access): `fseek`, `ftell` e `rewind`
Non siamo obbligati a leggere un file solo dall'inizio alla fine! Possiamo spostare il cursore del file in qualsiasi byte usando:
- **`fseek(fp, offset_in_byte, origine)`**: sposta il cursore di `offset_in_byte` (tipo `long`, anche negativo) rispetto a `origine`, che può essere:
  - **`SEEK_SET`**: dall'**inizio** del file (byte 0).
  - **`SEEK_CUR`**: dalla **posizione corrente** del cursore.
  - **`SEEK_END`**: dalla **fine** del file.
- **`long pos = ftell(fp)`**: restituisce la posizione corrente del cursore in byte dall'inizio del file. *(Trucco classico: fare `fseek(fp, 0, SEEK_END); long dim = ftell(fp);` permette di sapere quanti byte è grande un file binario!).*
- **`rewind(fp)`**: riporta il cursore all'inizio del file (equivale a `fseek(fp, 0, SEEK_SET)`).

## Esempi guidati

### Esempio 1: Lettura di numeri da un file di testo e scrittura di statistiche su un altro file
Leggiamo tutti i voti presenti in `voti.txt` e scriviamo il conteggio e la media in `report.txt`.

```c
#include <stdio.h>

int main(void) {
    FILE *in = fopen("voti.txt", "r");
    if (in == NULL) {
        perror("Errore apertura voti.txt");
        return 1;
    }

    int voto;
    int somma = 0;
    int cont = 0;

    /* Ciclo di lettura CORRETTO senza usare feof! */
    while (fscanf(in, "%d", &voto) == 1) {
        somma += voto;
        cont++;
    }
    fclose(in); /* Chiudiamo subito il file di input */

    FILE *out = fopen("report.txt", "w");
    if (out == NULL) {
        perror("Errore apertura report.txt");
        return 1;
    }

    if (cont > 0) {
        fprintf(out, "Esami registrati: %d\nMedia aritmetica: %.2f\n",
                cont, (double)somma / cont);
    } else {
        fprintf(out, "Nessun voto presente nel file.\n");
    }

    fclose(out);
    return 0;
}
```

### Esempio 2: Salvataggio e rilettura ad accesso diretto (`fseek`) di `struct` su File Binario
Salviamo un vettore di 3 strutture `Prodotto` in un file binario `catalogo.bin`, e poi leggiamo direttamente il **secondo prodotto** (indice `1`) saltando il primo grazie a `fseek`!

```c
#include <stdio.h>

typedef struct {
    int id;
    char nome[20];
    double prezzo;
} Prodotto;

int main(void) {
    Prodotto elenco[3] = {
        {1, "Tastiera", 45.00},
        {2, "Mouse",    25.50},
        {3, "Monitor", 199.90}
    };

    /* 1. Scrittura binaria dell'intero array di 3 strutture */
    FILE *fp = fopen("catalogo.bin", "wb");
    if (fp == NULL) return 1;
    fwrite(elenco, sizeof(Prodotto), 3, fp);
    fclose(fp);

    /* 2. Riapertura in lettura binaria e salto diretto al record di indice 1 ("Mouse") */
    fp = fopen("catalogo.bin", "rb");
    if (fp == NULL) return 1;

    /* Ci spostiamo di 1 * sizeof(Prodotto) byte dall'inizio del file (SEEK_SET) */
    fseek(fp, 1L * (long)sizeof(Prodotto), SEEK_SET);

    Prodotto letto;
    if (fread(&letto, sizeof(Prodotto), 1, fp) == 1) {
        printf("Record letto direttamente: ID=%d, Nome=%s, Prezzo=%.2f\n",
               letto.id, letto.nome, letto.prezzo);
    }

    fclose(fp);
    return 0;
}
```

## Errori frequenti

1. **Aprire un file importante con `"w"` quando si voleva solo leggere (`"r"`) o aggiungere in fondo (`"a"`)**
   La modalità `"w"` **distrugge istantaneamente tutto il contenuto preesistente del file** nel momento stesso in cui viene eseguita `fopen`!
2. **Usare `while (!feof(fp))` come guardia del ciclo di lettura**
   Come dimostrato sopra, causa l'elaborazione duplicata dell'ultimo record. Controlla sempre il valore restituito da `fscanf`, `fgets`, `fgetc` o `fread`.
3. **Dimenticare `fclose(fp)` o chiudere un puntatore `fp` che vale `NULL`**
   Chiamare `fclose(NULL)` quando `fopen` è fallita causa un *Segmentation Fault*! Controlla sempre prima `if (fp == NULL) return 1;`.

   Indica quale stringa di modalità (`"r"`, `"w"`, `"a"`, `"rb"`, `"r+"`, ecc.) bisogna passare a `fopen` in ciascuno dei seguenti scenari:
   a) Aggiungere una riga di log in fondo a un file di testo `eventi.log` senza cancellare i log precedenti (creando il file se non esiste).
   b) Leggere un array di `double` salvato in formato binario dal file `misure.dat`.
   c) Leggere e modificare sul posto alcuni record di un file binario `archivio.bin` già esistente senza cancellarne il contenuto all'apertura.

> - **b)** **`"rb"`** (*Read Binary*).
> - **c)** **`"r+b"`** (oppure `"rb+"`: lettura e scrittura binaria senza troncamento iniziale).

2. **[Base — Copia di un file carattere per carattere]**
   Scrivi un programma C che copi interamente il contenuto del file `origine.txt` in un nuovo file `copia.txt` leggendo un carattere alla volta con `fgetc` e scrivendolo con `fputc`, controllando correttamente gli errori di apertura.
> [!tip]- Soluzione
> ```c
> #include <stdio.h>
> 
> int main(void) {
>     FILE *src = fopen("origine.txt", "r");
>     if (src == NULL) {
>         perror("Errore apertura origine.txt");
>         return 1;
>     }
> 
>     FILE *dst = fopen("copia.txt", "w");
>     if (dst == NULL) {
>         perror("Errore apertura copia.txt");
>         fclose(src); /* Non dimenticare di chiudere src prima di uscire! */
>         return 1;
>     }
> 
>     int c; /* Tipo int obbligatorio per confrontare con EOF! */
>     while ((c = fgetc(src)) != EOF) {
>         fputc(c, dst);
>     }
> 
>     fclose(src);
>     fclose(dst);
>     return 0;
> }
> ```

4. **[Intermedio — Calcolo della dimensione in byte di un file con `fseek` e `ftell`]**
   Scrivi una funzione `long dimensione_file(const char *nome_file)` che determini e restituisca il numero totale di byte di un file qualsiasi posizionando il cursore alla fine del file con `fseek` e interrogandolo con `ftell` (o `-1` in caso di errore).
> [!tip]- Soluzione
> ```c
> #include <stdio.h>
> 
> long dimensione_file(const char *nome_file) {
>     FILE *fp = fopen(nome_file, "rb");
>     if (fp == NULL) {
>         return -1L;
>     }
> 
>     if (fseek(fp, 0L, SEEK_END) != 0) {
>         fclose(fp);
>         return -1L;
>     }
> 
>     long byte_totali = ftell(fp);
>     fclose(fp);
>     return byte_totali;
> }
> ```

5. **[Intermedio/Esame — Filtro da file di testo strutturato a righe]**
   Un file di testo `studenti.txt` contiene su ogni riga: `matricola cognome voto` (es. `10425 Rossi 28`).
   Scrivi una funzione `int salva_promossi(const char *file_in, const char *file_out, int voto_minimo)` che legga tutte le righe di `file_in` con `fscanf`, scriva in `file_out` solo gli studenti con `voto >= voto_minimo` e restituisca il numero di studenti salvati (o `-1` in caso di errore di apertura file).
> [!tip]- Soluzione
> ```c
> #include <stdio.h>
> 
> int salva_promossi(const char *file_in, const char *file_out, int voto_minimo) {
>     FILE *in = fopen(file_in, "r");
>     if (in == NULL) return -1;
> 
>     FILE *out = fopen(file_out, "w");
>     if (out == NULL) {
>         fclose(in);
>         return -1;
>     }
> 
>     int matricola, voto;
>     char cognome[64];
>     int salvati = 0;
> 
>     /* fscanf restituisce 3 finché riesce a leggere tutti e 3 i campi della riga */
>     while (fscanf(in, "%d %63s %d", &matricola, cognome, &voto) == 3) {
>         if (voto >= voto_minimo) {
>             fprintf(out, "%d %s %d\n", matricola, cognome, voto);
>             salvati++;
>         }
>     }
> 
>     fclose(in);
>     fclose(out);
>     return salvati;
> }
> ```

6. **[Esame — Aggiornamento *in-place* di un record in un file binario con `r+b` e `fseek`]**
   Un file binario `conti.bin` contiene una sequenza di strutture `typedef struct { int id_conto; double saldo; } Conto;`.
   Scrivi una funzione `int accredita_su_conto(const char *nome_file, int indice_record, double importo)` che apra il file in modalità `"r+b"`, salti direttamente al record di posizione `indice_record` ($0, 1, 2, \dots$), lo legga con `fread`, aggiunga `importo` al campo `saldo` e **riscriva il record aggiornato esattamente nella stessa posizione** sul file!
> [!tip]- Soluzione
> *Punto chiave da esame*: dopo aver letto il record con `fread`, il cursore del file è avanzato al record successivo (`indice_record + 1`)! Prima di chiamare `fwrite` dobbiamo quindi **riposizionare il cursore indietro** all'inizio di `indice_record` con `fseek`!
> ```c
> #include <stdio.h>
> 
> typedef struct {
>     int id_conto;
>     double saldo;
> } Conto;
> 
> int accredita_su_conto(const char *nome_file, int indice_record, double importo) {
>     FILE *fp = fopen(nome_file, "r+b");
>     if (fp == NULL) return 0;
> 
>     long offset = (long)indice_record * (long)sizeof(Conto);
> 
>     /* 1. Sposta il cursore sul record da leggere */
>     if (fseek(fp, offset, SEEK_SET) != 0) {
>         fclose(fp);
>         return 0;
>     }
> 
>     Conto c;
>     if (fread(&c, sizeof(Conto), 1, fp) != 1) {
>         fclose(fp);
>         return 0; /* Indice oltre la fine del file */
>     }
> 
>     /* 2. Modifica il saldo in memoria */
>     c.saldo += importo;
> 
>     /* 3. FONDAMENTALE: riporta il cursore a 'offset' prima di sovrascrivere! */
>     fseek(fp, offset, SEEK_SET);
>     fwrite(&c, sizeof(Conto), 1, fp);
> 
>     fclose(fp);
>     return 1;
> }
> ```
